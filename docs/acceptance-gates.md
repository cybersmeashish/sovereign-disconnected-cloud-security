# Acceptance evidence before operational use

| Gate | Exercise | Record |
| --- | --- | --- |
| Local autonomy | Remove the enterprise connection in a representative authorized lab | Identity, detection, evidence and response observations |
| Revocation and time | Revoke a local role and simulate a bounded clock/service failure | Effective authority, renewal dependencies and failure behavior |
| Update handling | Present altered, wrong-destination, replayed and incompatible synthetic packages | Rejection behavior, trust inputs and permitted rollback |
| Disclosure | Attempt permitted and denied synthetic report exports | Approved fields, recipient, custody and audit observations |
| Visibility | Delay or omit a report | Explicit freshness and unavailable-site state |
| Recovery | Restore protected state and keys into the approved boundary | Observed recovery result and remaining dependencies |
| Capacity | Replay a representative authorized workload against the selected products | Measured ingest, backlog, search behavior, recovery and resource use |

These are proposed gates. The capacity calculation's local tests do not establish these operational outcomes.
