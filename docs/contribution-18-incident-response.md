# 18 — Disconnected incident-response playbooks

[Exercise-backed playbooks](playbooks/disconnected-response.md) assign a local decision owner, containment action, evidence to retain and stop criterion for compromised accounts, suspicious imports, identity dependency failure and central disconnection.

Live reference exercises revoke a synthetic account, reject a changed package and deny authorization when local time is unusable. External connectivity is actually unavailable while local scoped actions continue. The dependency fault matrix models identity/service outages; it does not crash a production IdP. Human roles are synthetic assignments, and no customer incident, organization readiness or operational response-time objective is claimed.
