# 22 — Control-to-evidence mapping

[Selected control mapping](../research/control-evidence.csv) links NIST SP 800-53 identifiers to an accountable deployment role, concrete reference artifacts, test/evidence pointers and unresolved operational gaps. Titles come from NIST's official OSCAL catalog snapshot.

Use it as an assessment aid: select applicable controls, appoint real owners, validate the environment and retain findings. Artifact presence and passing reference tests do not establish implementation of an entire control, regulatory compliance, audit certification or national accreditation. Mapping status is deliberately limited to the demonstrated reference scope.
