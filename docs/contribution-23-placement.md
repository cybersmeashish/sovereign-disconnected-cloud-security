# 23 — Placement and residency assurance

[Placement assessment](../assurance/inventory.py) separates declared regions, conflicts and matching claims that still need independent evidence. Workload, backup, evidence and recovery placement are assessed separately. Tests show that an authenticated or matching declaration alone cannot establish physical residency.

[Placement worksheet](../templates/placement-assurance.md) asks for physical/platform evidence, custody, operators and recovery locations. The supplied [NIST SP 1800-19 preliminary draft](https://csrc.nist.gov/pubs/sp/1800/19/iprd) is a historical research source, marked obsoleted by a later draft. Access to candidate newer pages returned HTTP 403 during this review; this repository does not assert their current publication status. No remote attestation or provider residency was measured.
