# Original experimental results — local authority during disconnection

Ashish Srivastava · 18 November 2026 · reference experiments

## Question and method

Which declared local actions survive external disconnection, and where do apparently valid security artifacts fail to establish freshness, completeness or recovery assurance?

Run a pinned Linux container with no external interface, a non-root process, read-only root and limited scratch tmpfs. Exercise scoped local identity, signed package admission, two-duty approvals, staged updates, monitoring, filtered export, signed audit checkpoints and clean restoration. Retain raw outcomes and source hashes. Repeat 102 regression cases on host and container. Run maintained OpenSSL PQ/interop checks separately on the host.

## Findings

1. Local scoped reads and approved review acknowledgments succeed while cross-site/cross-tenant access fails and an external connection returns `ENETUNREACH`. This establishes the fixture's local behavior inside a network namespace.
2. Signed bytes alone are insufficient for admission: wrong site/architecture/builder/subject or missing independent approvals are rejected. A fresh in-memory gate still accepts an old signed release. Durable anti-rollback state is an unresolved investment.
3. Central freshness changes the conclusion without changing report content: at simulated time 100 all sites are current; at 161 the conclusion is false.
4. A trusted signed audit checkpoint detects record truncation and a fully rehashed replacement chain. Its own external custody is a separate requirement.
5. A known-rule alert is emitted; an unknown event type is missed. Retention/backlog loss is observable through counters rather than hidden.
6. Clean recovery restores three synthetic records, configuration and software keys, while one later record is absent. Median measured fixture restoration is **0.000487 seconds** across five runs; this is not whole-site recovery.
7. Actual OpenSSL ML-KEM/ML-DSA and Ed25519 interoperability checks pass. Altered ML-KEM ciphertext can be rejected implicitly through a different secret; exit status alone is insufficient.
8. Matching placement declarations remain claims requiring independent evidence.

Container quota: one CPU, 256 MiB, 64 processes. Visible logical CPUs may exceed the quota. Small batches, timer scale, deterministic data, tmpfs and five trials limit generalization.
